# 人工智能训练营——高阶任务

## 概述

任务很简单，尝试做一个原型系统，吧我们暑假这们课智能化了。可以用到github上本课程所有的素材。实现做一个web平台，用户可以登陆学习这么课程，课程由AI教师讲授。由AI助教答疑。可以提交作业，由AI助教批改，给出评价。

## 具体功能

1. 设计一个剧本，AI教师按照剧本上课
2. 有一个web界面，用户可以上课，AI教师讲授，文字讲授，就像Galgame一样。
3. 讲到某个位置，会跟学生互动，提问，学生回答
4. 评价学生回答，并记录，后期用于生成学习报告
5. 布置作业，批改作业，评分，类似于上面一条
6. 一个单元，或者一部分内容讲完以后，生成学习报告
7. 总体来说就是一个galgame，你就把他当作galgame来做就行

## 项目提交要求

1. 必须用github提交，git管理项目
2. 提交一个项目结题报告，做一个ppt报告，演示运行
3. 不需要做完整的课程，只要有2-3个内容就行
4. 预计10月底以前完成
5. 就把它当作一个galgame来做就行
6. 使用langchain来做
7. 如果需要LLM的API可以找我，我可以提供一些额度
8. 两队做同一个，做的好的团队500元奖励
