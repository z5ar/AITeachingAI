# 前端（static 文件夹）说明

本项目前端为纯静态页面，主要文件包括：
- `index.html`：主页面结构，包含对话区、侧边栏、各类模态框（登录/注册/学习报告/历史/答疑等）、PPT图片展示区、头部用户信息区。
- `app.js`：核心交互逻辑，负责 UI 渲染、事件绑定、API 调用、进度与学习时长管理、判题与报告生成、主题切换、用户登录注册等。
- `style.css`：样式文件，定义整体布局、主题色、夜间模式、模态框、按钮等样式。

## 主要功能模块

### 1. 课程与小节选择
- 左侧栏展示课程与章节，支持章节分组与折叠。
- 选择课程后可浏览各小节，进入小节前弹出模态确认。

### 2. 主对话区
- 渲染学习流程，包括文本、视频、题目（选择/填空/简答/互动）、PPT图片。
- 支持“上一条/下一条”切换，自动保存进度。
- PPT图片自动显示于对话区上方，支持高度自适应。

### 3. 判题与学习报告
- 题目支持自动判分，简答题调用教师 API。
- 所有判题历史自动记录，学习报告可一键生成并上传。
- 学习报告支持换行显示，内容完整。

### 4. 学习时长统计
- 仅统计页面可见且窗口有焦点的时间，按用户+小节持久化。
- 时长实时显示于页面。

### 5. 用户系统
- 登录、注册、注销、修改密码均为模态弹窗。
- 用户信息悬浮显示，支持昵称编辑、主题色切换、夜间模式。
- 头像支持像素化显示。

### 6. 进度与本地存储
- 进度、答题草稿、视频播放进度均本地持久化，支持断点续学。
- 自动与云端同步，优先使用最新进度。

### 7. 其他功能
- 对话历史、学习报告、答疑均为独立模态弹窗。
- 答疑支持上下文定位，自动关联当前对话项。
- 主题色与夜间模式可随时切换，自动保存。

## 主要事件与 API 流程
- 页面加载：绑定事件、检测登录状态、加载课程。
- 进入小节：弹窗确认，获取首步内容，初始化学习时长与判题历史。
- 对话流程：每步渲染内容，题目自动判分并记录历史，支持答疑。
- 学习报告：收集判题历史与时长，生成报告并上传。
- 用户操作：登录/注册/注销/改密均为 API 调用，UI自动刷新。

## 扩展与维护建议
- 所有主要 UI 组件均有独立 DOM id，便于扩展。
- API 路径与参数详见后端 `api/README.md`。
- API 文档也可在运行`app.py`后，访问`/docs`查看。
- 新增题型、模态或功能建议在 `app.js` 中按模块拆分函数。
- 样式可通过 `style.css` 主题变量快速调整。
